# 🌿Gröna Oasen
Gröna Oasen är en responsiv webbutik för växter där användare kan utforska olika växter och läsa produktinformation i en modern och användarvänlig design.
Detta projekt är skapat för utbildningsändamål.

## Tekniker
- HTML5
- CSS
- JavaScript
- Figma

## Funktioner och innehåll
- Responsiv design för mobil, surfplatta och dator
- Tre sammanlänkade webbsidor
- Presentation av företaget och dess produkter
- Tydlig navigation mellan sidorna
- Produktkort med bilder och information
- Kontaktinformation och kontaktformulär
- Anpassat innehåll för målgruppen växtintresserade kunder
- Versionshantering med Git och GitHub
